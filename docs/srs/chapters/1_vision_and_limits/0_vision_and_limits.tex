\section{Visão e Limites}
\subsection{Objetivo do Sistema}
O projeto visa desenvolver uma pipeline automatizada para executar e comparar ataques adversariais em LLMs, permitindo avaliar e comparar a robustez de diferentes modelos.

As LLMs alvo dos ataques serão utilizadas para gerar código potencialmente vulnerável. A eficácia dos ataques será avaliada com base na análise da vulnerabilidade do código produzido.

O sistema incluirá também uma interface web para gerir, simular e analisar os ataques.
